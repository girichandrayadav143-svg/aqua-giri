│                                                                         │
│ Connection string looks like:                                           │
│ mongodb+srv://aqua_farming_admin:PASSWORD@cluster.mongodb.net/...      │

Step 2: Create GitHub Repository (3 min)
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Go to: https://github.com/new                                       │
│ 2. Create repository: "aqua-farming"                                    │
│ 3. In your computer terminal:                                           │
│                                                                         │
│    cd c:\Users\giric\OneDrive\Desktop\AQUA                             │
│    git init                                                             │
│    git add .                                                            │
│    git commit -m "AQUA Farming website"                                │
│    git remote add origin https://github.com/YOUR_USERNAME/aqua-farming│
│    git push -u origin main                                             │
│                                                                         │
│ 4. Verify files uploaded to GitHub                                     │
└─────────────────────────────────────────────────────────────────────────┘

Step 3: Deploy to Render (5 min)
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Go to: https://render.com                                           │
│ 2. Sign up with GitHub                                                  │
│ 3. Click: "New +" → "Web Service"                                      │
│ 4. Select your "aqua-farming" repository                               │
│ 5. Configure:                                                           │
│    Name: aqua-farming-prod                                             │
│    Environment: Node                                                    │
│    Build Command: npm install                                          │
│    Start Command: npm start                                            │
│ 6. Add Environment Variables:                                          │
│    NODE_ENV = production                                               │
│    PORT = 5000                                                         │
│    JWT_SECRET = MySecret123!@#Random                                   │
│    MONGODB_URI = mongodb+srv://aqua_farming_admin:PASSWORD@...         │
│    CORS_ORIGINS = https://aqua-farming-prod.onrender.com              │
│ 7. Click: "Create Web Service"                                         │
│ 8. Wait 2-3 minutes...                                                 │
│                                                                         │
│ YOUR WEBSITE IS LIVE! 🎉                                               │
│ URL: https://aqua-farming-prod.onrender.com                            │
